# 机械设计基础学习站

面向个人复习使用的机械设计基础学习网站。题库按题型拆分成三个子站，支持搜索、答案解析、错题次数记录和教材页码对照。网站为静态网页，电脑和手机都可以通过浏览器打开，无需安装软件。

## 在线访问

- [学习站首页](https://paloma421-tong.github.io/mechanical-design-basics-study/)
- [网站使用指南](https://paloma421-tong.github.io/mechanical-design-basics-study/使用指南/)
- [习题集](https://paloma421-tong.github.io/mechanical-design-basics-study/习题集/)

- [选择题](https://paloma421-tong.github.io/mechanical-design-basics-study/选择题/)

## 快速使用

1. 打开学习站首页，选择要练习的子站；也可以直接点上面的子站链接。
2. 使用搜索框查找题目、章节或答案关键词。各子站可以按页面提供的题型、章节或排序选项筛选。
3. 点击“查看答案”或“展开本页”查看答案与解析；“展开全部答案”可以一次打开当前列表中的答案。
4. 在习题集里点击“原题页与图示”核对原题；点击绿色教材页码在侧边阅读教材。看完后点“回到原题页”返回当前题目。
5. 学习站的章节目录可以收起；教材阅读栏可以调整宽度、移到另一侧，也可以点“新标签页”单独打开 PDF。

## 错题复习

每道题旁边都有“错一次”和“已学会”按钮。

- 每点一次“错一次”，该题的错题次数加 1。
- 点“已学会”会把该题的错题次数清零。
- 习题集支持按错题次数优先排序，方便先复习常错内容。
- 各子站的错题记录分别保存，不会混在一起。

## 学习记录与跨设备使用

网站内容可通过上面的在线地址在不同设备访问。学习进度和错题次数保存在当前浏览器中，因此不同设备或不同浏览器之间不会自动同步；清除浏览器站点数据也会清空这些记录。更换设备时，网站本身仍可打开，但需要在新设备上重新记录学习进度。

## 后续更新

本仓库保存 GitHub Pages 使用的网站发布文件和运行所需资源，不包含原始 Word 文档及本地整理脚本。新增或修订题目、答案、教材资料时，请在本地源工程中更新并重新生成相应子站，再同步生成的网站文件与资源到本仓库。

GitHub Pages 已配置为从 `main` 分支的仓库根目录发布。更新后若网页仍显示旧内容，可稍后刷新；Windows 浏览器可使用 `Ctrl + F5` 强制刷新。
