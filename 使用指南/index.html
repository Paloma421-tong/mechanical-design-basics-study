建议的练习流程

1. 选题库并定位用章节目录、筛选菜单或搜索框找到要练的内容。
2. 先独立作答先想清楚答案，再点“查看答案”或展开本页，检查自己的思路。
3. 查看解析与出处对照答案解释；习题集可点绿色教材页码打开对应教材页。
4. 记录错题并复习答错时点“错一次”；学会后点“已学会”清零，再按错题次数排序复习。

答案如何展开和收起

点击单题的答案栏可单独展开或收起；“展开本页”控制当前题页的所有答案，“展开全部答案”控制当前筛选结果中的答案。点击“错一次”或“已学会”不会收起已经展开的答案。

在习题集里对照原题和教材

  • 点“原题页与图示”查看习题集对应原页。
  • 点答案下方的绿色教材页码，在侧边阅读栏查看教材扫描页；可翻页、缩放、调整阅读栏宽度或移动到另一侧。
  • 看完教材后点“回到原题页”，返回相关题目继续练习。

错题次数与学习进度

  • 每点一次“错一次”，这道题的错题次数增加 1。
  • 点“已学会”会把这道题的错题次数清零；它不会删除题目，也不会关闭已展开的答案。
  • 习题集提供“错题次数优先”排序；其他子站也会展示各题的错题次数。
  • “标为学完”记录页面学习状态，与错题次数分开。
记录保存在当前浏览器。网站内容可以在不同设备上打开，但错题次数和学习进度不会自动跨设备同步。换设备或换浏览器后，网站仍可用，只是学习记录需要重新建立；清除站点数据也会清掉本机记录。

常见情况

教材页面打开较慢

首次查看某页时需要从网站加载教材页面图片；后续浏览器通常会使用缓存。网络较慢时稍等片刻，或点“新标签页”打开 PDF。

更新后仍显示旧页面

GitHub Pages 更新可能需要一点时间。等待后刷新页面；Windows 浏览器可按 Ctrl + F5 强制刷新。
